# 南向资金观测模式（2026-06-05 案例）

## 窗口期数据（2026-06-05 至 2026-06-09）

| 日期 | 南向净买（亿港元） | 信号 | 背景 |
|------|-------------------|------|------|
| 06-05 | -24.26 | 净卖（避险） | 美股暴跌当夜，资金撤出港股 |
| 06-08 | +113.18 | 巨量净买（抄底） | 港股/科技股回调后低吸 |
| 06-09 | -86.14 | 净卖（反复） | 隔夜美股未企稳，短线获利了结 |

## 模式识别原则

- **单日净买卖不可孤立解读**：三日窗口波动从 -24 → +113 → -86，单一数字完全不足以判断资金方向
- **连续趋势优于单日**：若出现「净买→净买→净买」或「净卖→净卖→净卖」三日连续，方能初步判断方向
- **三端联动法**：同时观察 A 股指数（量价）、港股指数（量价）、离岸人民币汇率（CNH）三者。若三者同向，信号增强；若背离，资金行为可能无趋势
- **波动幅度量化**：案例中 06-08 单日 +113 相对前日 -24 波动达 570%，说明情绪极端，趋势不持久（次日报复性净卖 -86 验证了此判断）

## 常见信号解读

| 模式 | 解读 |
|------|------|
| 大跌日净买骤增（>100亿） | 抄底，但可能为短线 |
| 大跌日净卖 | 资金避险，看空港股 |
| 大幅净买后次日大幅净卖 | 短线抄底后出货，市场未企稳 |
| 连续三日净买且幅度递减 | 趋势性流入，风险偏好提升 |
