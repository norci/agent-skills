# 北向数据制度说明

## 官方口径变更

2024-08-19 起，沪深港通交易机制调整，北向日度买入/卖出拆分及净买入/净流入已非官方披露字段。AKShare 旧字段（如 `money_type="北向"`）返回 `NaN`/`0.0`，乃旧字段无官方来源的表现——非临时缺数，非外资零流入/流出。

## 替代指标（可用）

| 数据类 | 接口 | 说明 |
|--------|------|------|
| 沪深股通成交总额 | AKShare `stock_hsgt_hist` | 渠道活跃度 |
| 总成交笔数 | 同上 | 通道利用频率 |
| ETF 成交额 | `stock_hsgt_hist_em`（部分） | 被动资金线索 |
| 前十大活跃证券 | `stock_hsgt_top10_em` | 单日活跃标的 |
| 季度持仓 | `stock_hsgt_hold_stock_em` | 跨境配置趋势（滞后） |
| 南向（港股通） | 同批接口，方向不同 | 中资跨境情绪 |

## 间接指标

- 美元指数（DXY）—— 资本回流压力
- 美债利率 / 代理实际利率 —— 全球无风险利率锚
- 人民币汇率（CNY/CNH）—— 跨境资金成本
