# 金融市场分析法

## 数据纪律

四态判别（数据存在 / 官方不披露 / 接口失败 / 维度不存在）与缺失值处置见 `financial-market-data` 技能，此处不重复。本技能只管一件事：字段确已不可得时，用哪个指标替代。

### 以可用指标代缺失字段

以北向资金为例：2024-08-19 后日度净买入/净卖出已非官方披露字段，AKShare 旧字段返回 `NaN`/`0.0` 是旧字段残留。不得解释为"外资零流入"。

替代指标：
- 沪深股通成交总额、总成交笔数、ETF 成交额
- 前十大活跃证券成交明细
- 季度持仓变化
- 南向资金（港股通可用）
- 间接指标：美元指数、美债利率、人民币汇率
- 北向数据制度说明见 `references/northbound-data.md`

## 因果验证法

### 充分必要条件检验

市场分析中，历史相关 ≠ 逻辑因果。每一条传导路径须列明充分必要条件，逐项检验当次事实，未满足者降为"待证机制"，不得径称成立。

标准模板——传导链检验：

```
机制名称：[例如 美股暴跌→跨境联动→A 股承压]

条件 A：源头事件确认（美股当夜/当日是否确有大跌）
条件 B：目标市场在窗口期内同步反映
条件 C：通道指标有数据支撑（价量联动、汇率、资金异动）
条件 D：备择解释被排除（内因、政策、流动性等）

检验结果：A√ / B√ / C√ / D?  →  核心成立，备择待排除
```

### 备择排除层级（优先顺序）

条件 D 是最容易被忽略的环节：

1. **内因排除**：该市场当日是否有独立利空（政策、监管、公司事件）？若内因可解释全部跌幅，外部传导不成立；若内因与外因同时存在，注明"叠加效应"
2. **政策排除**：是否存在可能扭曲分析的政策发布（降准、利率调整、交易规则变动）？
3. **流动性排除**：当日是否有宏观流动性事件（央行操作、互换工具、外资配额变动）？
4. **技术性排除**：是否有衍生品到期、权重股除权、指数调整导致的被动买卖？

备择未被排除时标注 D?，结论降级为"核心成立，备择待排除"。

### 板块分化法则

外部冲击传导至 A 股时，不同板块跌幅差异显著。分析当区分品种受力点：

- 科技/成长（科创50、创业板指）：情绪敏感，常为外部冲击放大端
- 大盘蓝筹（上证50、沪深300）：相对抗跌
- 整体（上证综指、万得全 A）：提供基准参照

应报告最大/最小板块差异倍数，避免笼统以"A 股下跌"一言蔽之。

## 南向资金观察法

南向（港股通）数据仍为可用跨境指标：

- 单日净买入/净卖出波动极大，不可孤立解读
- 连续多日趋势胜于单日数值
- 结合港股/A 股/汇率三者联动判断资金意图：避险 / 抄底 / 双向波动
- 具体案例与量化窗口见 `references/southbound-patterns.md`

## 数据获取原则

- 实时 API 优先，记忆中的历史模式不可替代当次事实
- 数据日期精确到日，来源（接口名、数据商）明标
- API 失败时先排错（代理、参数、权限），不可虚构数据
