# 用语法树清点全仓

## 判据：AST 答人口问题，LSP 答符号问题

| 问题 | 工具 |
|---|---|
| 全仓有多少个同类常量、各是什么值 | 语法树（本技能） |
| 某个配置项的有效值是多少 | 语法树静态求值（本技能） |
| 这个符号被谁引用、改名波及哪些文件 | LSP（find_references / rename_symbol） |
| 这两个定义是不是同一职责的两份实现 | 语法树列同名定义，再读那两处判断 |

「逐个读文件找数字」与「grep 后人工筛」都是绕行：语法树一次扫完，输出带文件名与行号，可直接跳过去读那一处。

## 两个脚本

`scripts/static_eval.py` 不执行模块地算出模块级赋值的值。配置散在字典、类属性、跨模块导入里时，读源码看不出值，而 `import` 会联网、读凭证、写文件。求不出的值返回「未知」，两类原因：引用了运行期才知道的东西（环境变量、函数返回、当前时间），或求值器不认识该语法。

```
python static_eval.py <模块路径>             # 列出全部模块级赋值
python static_eval.py <模块路径> 名字 [名字…]   # 只列指定名字
```

`scripts/scan.py` 五个子命令，各答一类人口问题。每个都接受 `--filter` 正则与 `--skip` 目录；缺省跳过虚拟环境、版本库与测试文件。

```
python scan.py constants  <根>   # 模块级常量：哪个模块写死了数字或短容器
python scan.py calls      <根>   # 调用实参：谁给哪些函数传了什么
python scan.py numbers    <根>   # 函数内数字字面量，按作用域归类
python scan.py imports    <根>   # 模块级导入边：改模块位置前看谁依赖谁
python scan.py duplicates <根>   # 同名顶层定义出现在两处以上
```

## 用法：先定要答的问题，再选子命令

| 要答的问题 | 怎么调 |
|---|---|
| 某类窗长、阈值、超时分别写在哪 | `constants` 配 `--filter 'period\|window\|timeout'`，再 `static_eval` 取有效值 |
| 某个量到底由谁产生、怎么传给下游 | `calls` 配 `--filter 'rolling_\|shift\|upto'`，看参数实参名 |
| 某个模块被谁依赖，挪走会不会断 | `imports` 配模块名前缀 |
| 同一职责是否已有第二份实现 | `duplicates`，再读命中的那两处 |
| 哪个函数里藏了魔数 | `numbers` 配 `--filter '路径片段'` |

被问到的量在运行期才有值时（读环境变量、由函数算出），静态求值给「未知」；此时改为在项目里跑一次那行代码取值，不要拿「未知」当结论。

## 加子命令

新的清点问题按同一个形状加进 `scan.py` 的 `COMMANDS`：收路径表与按名正则，往标准输出逐行写「文件:行号  事实」。不写返回值、不建类、不加配置项——一次扫描只答一个问题。

## 界限

模块级作用域之外的值不求：函数体内的赋值依赖调用序，静态求不出，也不该求。需要知道某次调用的实参值，用 `calls` 看源码里的实参表达式，再问运行期。

同一份扫描不重复跑：先一次跑出全表再筛，不要为每个名字各跑一遍。
