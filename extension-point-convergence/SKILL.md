# 扩展点收敛（增量改动的架构卫生）

## 何时用

- 要加 / 删 / 改一条「规则、开关、判据、策略档、过滤器」。
- 已动手，发现同一个改动横穿 3 个以上文件（规则类 + 算法 + 数据容器 + 引擎分支 + 缓存键 + 编排预填）。
- 看到两个签名相同、实现几乎一样的函数。
- 改完想自查有无同类结构问题。

## 判据（动手前先数）

1. **一处规则改动触及的文件数 > 2 → 先收敛，别先实现**。若删一条规则要改 6 个文件，问题不在规则，在架构。
2. **同签名同实现的第二个函数 = 重复**。合并为一个函数 + 缺省参数（如 `eligible=None`），或让调用点自己拼；不要为「对照 / 诊断」在生产代码里注册第二个判据。
3. **一个函数里两件事（A ∧ B）= 粘着**。拆成有序管道：每步形如 `f(输入, 上游结果) → 结果`，前者之出即后者之域。
4. **默认行为 / 默认配置放在文件末尾 = 隐蔽**。声明面（类型、注册表、默认值、管道序）集中在文件头部，实现放后半。
5. **magic number 必须有依据**。参数若源自某已删机制（如某特权名单的长度），该机制一废，参数即无依据 —— 删或重定，别留。
6. **名字一名两义要拆**（如 `turnover` 既指成交额又指换手率）；`assemble_*` 之类不达意之名（实为状态摊到日轴）要正名。
7. **模块 docstring 不承载算法细节**：算法、口径、坑移到对应函数 docstring（就近可查），顶部只留概述与指针。

## 收敛模板（可操作）

一条扩展点 = 一份**可哈希规格（名 + 具名参数）** + 一个**注册表**，其余全通用：

- 规格对象：`@dataclass(frozen=True)`，参数用有序 tuple → 可作 memo 键，亦可序列化成缓存键串。
- 注册表：`dict[名, 函数]` + 装饰器登记（增一步只写一函数加一饰）。
- memo：容器上一个 `dict[规格键, 结果]`，不新增专用字段。
- 缓存键：`kind + 通用参数` 由一个泛化函数生成，不为每条新规则加一个 key 函数。
- 预填（编排层）：遍历当前任务集所用规格，统一 `prefill`。
- 取用（消费侧）：一个函数按规格取值，**只读，缺即 raise**（提示去编排入口），不在热路径现算。
- 管道：规格为 tuple，按序折叠；层序即规格序（把「先滤后去重」这类顺序写进默认值并注释）。

## 数据与并发类实证坑

| 现象 | 因 | 处置 |
|---|---|---|
| 净值某日数十倍跳变 | 僵尸合约：有行情行但成交 / 持仓恒 0，价格冻结；复效日跳到真实价位 | 选约 / 入池判据要求持仓或成交 `> 0`；统计「中位成交额」时**不可丢弃零值日**（`if amount:` 会把零日子整段跳过，中途复活者便漏网） |
| 段界虚假收益 | 拼接价在换段日水平跳变（不同合约价位差），被当收益计入 | 换段日的收益要么归零、要么按新合约起算 |
| 空表路径崩 `KeyError` | 空 `DataFrame` 无列 | 构造空表时显式给列名 |
| 「有档」判据误放行 | 「有表 / 有行」不等于「有数据」 | 就绪判据应含「有实际数据」一项 |
| 缓存反序列化 `AttributeError` | 被 pickle 的对象字段改名 / 删 | 缓存键须含代码 mtime（逻辑一变即失效），或同步迁移旧物 |
| 子进程写库报锁冲突，钩子明明关了连接 | Python ≥3.14 `multiprocessing` 默认 **forkserver**，`os.register_at_fork` 之 before 钩不生效，句柄被继承 | 显式 `multiprocessing.get_context("fork").Pool(...)` |
| 网络抖动即永久丢数据 | 网络失败与「无数据」混记同一断点 | 二者分账：网络失败**不记**断点（次跑重试），确认无数据才记（免重复订阅）；worker 返回「网络成否」标记，主进程只在成功时写 |
| 反复被限流 | 并发登录过多，靠重试硬扛 | 降并发 + 登录前随机错峰 + 保底退避重试，三者并用 |

## 验证与提交纪律

- **行为对拍**：同一输入在新旧代码下跑，数字须**逐位一致**（重构不改语义）；再多跑一遍全量用例，确认无档被跳过。
- 报「某档更优」时，换手 / 成本 / 持仓日数三项须与对照并列。
- **一步一功能点一 commit**；分支内可多 commit，毕后 squash。
- **文档与代码同清**：卷 / 文档里引用已删的函数名、词元、参数，随删除一并清理；旧结论有误就地改写，不留「前说已误」补丁。
- **不擅自扩大战线**：声明为实验性 / 不必兼容的旧脚本坏着不算你的活；但也别回退得半吊子（回退后引入新报错）。
- 大块替换前先精确读区间；`oldText` 须逐字（含全角、空白）。
- 手工往真库写过测试数据，事后要清理。
- 命名 / 风格检查器会误判（把类型别名、字符串字面量当数学量）：用 `choose_identifier_name` 复裁，**不要为过检取荒谬名**。
